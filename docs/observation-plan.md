# 5일 관찰 계획 (제출 폼 "5일 관찰 시작"에 붙여 넣을 내용)

> 5일 기록은 **실제로 서로 다른 날짜에** 폼에서 남겨야 합니다(시각은 서버가 정함). 아래는 1일차 시작 기록용 초안입니다. 숫자는 본인이 앱을 쓰며 직접 센 값이어야 합니다.

## 폼 입력값 (T07-C04~C08, C23~C27)
**5일 동안 답할 관찰 질문** (C04)
> 인증을 붙인 다이어리를 5일 동안 쓰면, 내가 하루에 완료 처리하는 할 일은 몇 개이고, 계획 규칙을 바꾸면 달라지는가?

**측정 지표** (C05)
> 하루에 완료 처리한 할 일 수 (앱 "② 할 일" 화면에서 그날 완료 시각이 찍힌 할 일을 센 값)

**측정 단위** (C06)
> 개

**집계·계산 규칙** (C08, C23~C27)
> 하루 값 = 그날(Asia/Seoul 기준) 완료 처리한 할 일 수. 합계 = 기록한 날의 하루 값 합, 평균 = 합계 ÷ 기록한 날 수.
> 결측값: 기록을 남기지 못한 날은 0으로 치지 않고 "기록 없음"으로 두며 평균 분모에서 제외한다.
> 중복값: 같은 할 일을 완료했다가 되돌리고 다시 완료해도 그날 1개로 센다(앱의 완료 기록은 할 일당 1건).
> 이상값: 하루 값이 20개를 넘으면 입력 실수 가능성이 있으니 앱 화면에서 다시 세어 확인하고, 그래도 맞으면 그대로 쓴다.
> 반올림: 평균은 소수 첫째 자리까지, 반올림은 half up(0.25 → 0.3).
> 주 시작 요일: 월요일.

**변경 전 계획 규칙** (사람이 읽는 문장, C09~C11)
> 매일 아침 그날 할 일을 개수 제한 없이 적는다.

## 일정 (C07, C09, C12)
| 시점 | 할 일 |
|---|---|
| 시작 전 | 폼에서 "5일 관찰 시작 기록 남기기" |
| 1일차 | 앱에서 계획·할 일 입력·완료, 폼 "1일차" 기록 |
| 2일차 | 폼 "2일차" 기록 |
| **2일차 기록 뒤 ~ 3일차 기록 앞** | 폼 **"규칙 1회 변경"** 기록: 계획 규칙을 `하루 할 일은 3개 이하로 제한한다`로 변경 + 바꾼 이유 한 줄 (C10, C11) |
| 3~5일차 | 변경된 규칙으로 계속 기록. 같은 지표·단위·계산 규칙으로 비교(C13~C15) |
| 5일차 끝 | 화면에 보이는 합계·평균을 5일 기록을 손으로 더한 값과 대조해 같음/다름을 제출물에 적기 (C132) |

## 바꾼 이유 / 결과 (본인이 직접 작성)
- 바꾼 이유(C11): 변경 시점에 실제 관찰을 한 줄로 — 예: "1~2일차에 할 일을 너무 많이 적어 절반도 못 끝냈다". 관찰이 없다면 규칙을 바꾸는 이유가 없습니다.
- 결과가 나빠졌다면 그대로 기록하고 왜 나빠졌는지 한 줄 적습니다.
